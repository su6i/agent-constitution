# 065 — Executor Routing (کدام اجنت، کدام کار)

منبع: تجربه‌های ثبت‌شده‌ی polycast (2026-07-11/12، حکم مالک). معمار موقع نوشتن هر
WO مجری را طبق این جدول تعیین و در سربرگ WO ثبت می‌کند. تخطی = WO ناقص.

## جدول routing

## قواعد مکمل
1. **جمینی شلخته فایل می‌سازد** (حکم مالک): هر task-brief ِ جمینی باید مسیر مطلق
   ِ دقیق هر خروجی و هر فایل ورودی را صریح بنویسد و محدوده‌ی نوشتنش
   (`experiments/<agent>/` + مسیرهای مجاز نام‌برده) را تکرار کند — وگرنه مخزن را
   به هم می‌ریزد.
2. تسک دیسک/محیط-سنگین: چک‌لیست sanity (فضای دیسک، mount، writable بودن مقصد)
   جزو گام ۰ ِ خود WO باشد.
3. گزارش مجری ارزان = ادعا، نه سند: پاس بازبینی معمار قبل از merge الزامی است و
   ادعاهای «ابزار خراب است» بدون verify مستقل وارد docs نمی‌شود.
4. از n=1 نتیجه‌گیری نمی‌شود؛ تغییر این جدول فقط با بنچمارک تکرارپذیر
   (پروژه‌ی ai-router) یا حکم مالک.
